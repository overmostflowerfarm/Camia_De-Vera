# Right Angle Hypotenuse Calculator
## Description
The ***Right Angle Hypotenuse Calculator*** is a python program used to calculate the hypotenuse of a right angle and rounds it up to the second decimal place.

It uses the **Pythagorean Theorem** to calculate the hypotenuse of *A* and *B*

**IMPORTANT REMINDER**: Use *valid* numerical values.

## How to Run
1. Click the python file

2. Run the python program and press the play button

3. Input your values

## Input Needed
- **Side A**
- **Side B**

**B**= 7
